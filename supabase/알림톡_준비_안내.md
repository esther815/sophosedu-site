# 소포스 저널 알림톡 — 켜기 전 준비 (원장님용)

소포스 저널을 게시하면(「올려」) 재원생 가족 중 구독한 분께 카카오 알림톡이 자동으로 나갑니다.
소포스·주니어솔로몬이 같은 설정을 함께 씁니다. 아래 순서대로 한 번만 준비하면 됩니다.

## 1. 원장님이 직접 하실 일

| 순서 | 할 일 | 어디서 |
|---|---|---|
| 1 | 소포스에듀 카카오톡 채널 개설 · 비즈니스 인증 | 카카오 비즈니스 (business.kakao.com) |
| 2 | 솔라피 가입 · 사업자 인증 · 충전 | solapi.com |
| 3 | 솔라피에 카카오 채널 연동 → 발신프로필 ID(pfId) 생성 | 솔라피 > 카카오 채널 |
| 4 | 아래 '알림톡 템플릿'을 솔라피에서 등록하고 심사 요청 | 솔라피 > 알림톡 템플릿 |
| 5 | 솔라피 API 키 발급 (API Key · API Secret) | 솔라피 > 개발 > API Key |

- 계약 전 솔라피에 확인할 것: **"재원생 가족이 구독 신청한 소포스 저널 새 글 안내"가 알림톡(정보성) 템플릿으로 승인 가능한지.**
  반려되면 광고성 메시지(브랜드 메시지)로 바꿔야 하고, 그 경우 '(광고)' 표기·야간 발송 제한 등 규정이 달라집니다.
- 개인정보 처리방침의 위탁 업체 칸에는 '솔라피(SOLAPI)'로 적어 두었습니다. 계약서의 정확한 상호로 바꿔야 합니다.
- 주니어솔로몬은 채널·템플릿을 따로 만들고 같은 솔라피 계정에 연동합니다.

## 2. 알림톡 템플릿 (심사 신청용 — 변수 이름을 바꾸지 마세요)

- 템플릿 이름: 소포스 저널 새 글 안내
- 메시지 유형: 기본형
- 본문:

```
[소포스 저널]
신청하신 소포스 저널에 새 글이 올라왔습니다.

■ #{제목}

#{요약}

■ 소포스 노트
#{노트}

※ 재원생 가족 중 소포스 저널 받아 보기를 신청하신 분께 보내 드립니다. 회원 서재에서 언제든 끄실 수 있습니다.
```

- 버튼: 웹링크 · 이름 「소포스 저널 보기」 · 주소 https://sophosedu.co.kr/brief.html (모바일·PC 같음)

## 3. 설정 값 넣기 (원장님 승인 후 작업 채팅이 진행, 또는 아래대로 직접)

1. Supabase 대시보드 > SQL Editor 에 `supabase/입시노트_알림톡_설정.sql` 을 붙여 넣고 실행.
2. 발송 함수 배포: `supabase functions deploy news-dispatch --no-verify-jwt`
   (GitHub 에서 부를 때는 로그인 토큰이 없으므로 `--no-verify-jwt`. 대신 함수가 비밀값으로 확인한다.)
3. Supabase > Edge Functions > Secrets 에 넣을 값:

| 이름 | 값 |
|---|---|
| DISPATCH_SECRET | 임의의 긴 문자열 (아래 GitHub 값과 같게) |
| ALIMTALK_MODE | 처음엔 `test` → 시험 발송 확인 후 `live` |
| TEST_PHONE | 원장님 휴대폰 (숫자만) |
| SOLAPI_API_KEY · SOLAPI_API_SECRET | 솔라피 API 키 |
| SOPHOS_PFID · SOPHOS_TEMPLATE_ID | 솔라피의 발신프로필 ID · 승인된 템플릿 ID |
| SOLOMON_PFID · SOLOMON_TEMPLATE_ID | 주니어솔로몬 준비되면 |

4. GitHub 저장소 Settings > Secrets and variables > Actions 에
   `NEWS_DISPATCH_URL` = `https://gyuuimwalbxsocnamtqk.supabase.co/functions/v1/news-dispatch`,
   `NEWS_DISPATCH_SECRET` = 위 DISPATCH_SECRET 과 같은 값.

## 4. 켜는 순서

1. `ALIMTALK_MODE=test` 상태에서 원장실 > 소포스에듀 > 「소포스 저널 알림톡」 > **시험 발송** → 원장님 휴대폰으로 오는지 확인.
2. 재원생 가족을 원장실 명단에서 **재원생 가족으로 승인** → 그 회원의 서재에 「소포스 저널 받아 보기」가 나타남 → 회원이 번호·동의 입력.
3. 이상 없으면 `ALIMTALK_MODE=live`. 이후 「올려」 = 게시와 동시에 발송.

## 5. 동작 규칙

- 보내는 대상: 원장님이 재원생 가족으로 승인 **그리고** 본인이 구독을 켠 회원만.
- 같은 기사는 같은 사람에게 한 번만 갑니다.
- 밤 9시~아침 8시에 게시하면 다음 날 08:05 에 보냅니다.
- `test` 기간에 올린 기사는 `live` 로 바꾼 뒤에도 학부모께 다시 나가지 않습니다.
- 재원생 승인을 해제하면 구독도 자동으로 꺼집니다.
- 발송을 잠시 멈추려면 `ALIMTALK_MODE=off`.
